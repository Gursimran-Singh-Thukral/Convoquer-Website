# Convoquer Frontend Static Assets (`client/public/images/`)

Place all frontend images in this folder. They can be referenced anywhere in React components using `/images/<filename>`.

### Recommended Assets:

- `hero-bg.jpg`: High-resolution drone/golden-hour photo of IIT Jammu Jagti Campus & sports arenas (used in `HeroSection.tsx`).
- `campus-map-satellite.jpg`: High-resolution satellite / drone GNSS view of IIT Jammu campus showing sports grounds, stadiums, and roads (used in `CampusMasterplanSection.tsx`).
- `iit-jammu-logo.png`: Official high-res logo of IIT Jammu / Board of Sports Activities.
- `venues/`: Photos of specific sports arenas (athletics track, cricket oval, indoor hall, volleyball courts).
- `sponsors/`: Partner logos (Shiv-Naresh, Cosco, Fast&Up, Red Bull, Sports J&K).
